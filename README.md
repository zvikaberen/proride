# ישראל סדובסקי — הסעות פרטיות

דף נחיתה סטטי להסעות פרטיות, בעברית ובאנגלית. הנהג הוא ישראל סדובסקי, והבסיס ברכסים. כל נסיעה היא ממקום אחד למקום שני, בכל הארץ, עם נהג אחד ורכב אחד, בלי החלפות. היציאה לא בהכרח מרכסים. נפתח ישירות מהדפדפן, בלי build. המתג עב / EN נמצא בראש הדף.

## הרצה מקומית

אפשר לפתוח את `index.html` בדפדפן, או להריץ שרת מקומי משורש הפרויקט:

```bash
python3 -m http.server 8941
```

ואז לגלוש אל [http://127.0.0.1:8941](http://127.0.0.1:8941).

## העלאה

התיקייה מוכנה ל-Netlify או ל-Vercel כאתר סטטי. שורש האתר הוא תיקיית הפרויקט, עם `index.html` בכניסה.

## מבנה

- `index.html` — הדף
- `css/style.css` — העיצוב
- `js/main.js` — תפריט מובייל ופס גלילה
- `assets/images/staria-van.jpg` — תמונת הרכב

השירות לא פעיל בשבת. זה מופיע בגוף הדף, בפס האמון, בסגירה ובתחתית המובייל.
